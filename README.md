# Doce Encanto

Projeto de site de confeitaria fictícia para a AV1.

## Tecnologias

- HTML
- CSS
- Bootstrap 5
- Google Fonts

## Estrutura

- `index.html` — página inicial
- `salgados.html` — cardápio de favoritos
- `doces.html` — doces
- `bolos.html` — bolos personalizados
- `contato.html` — contato e pedidos
- `css/styles.css` — estilos
- `imagem/` — imagens do projeto

## Como abrir

Abra o arquivo `index.html` em um navegador.
