# Doce Encanto

Projeto de site responsivo para uma confeitaria fictícia, desenvolvido para a AV2.

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5.3
- Google Fonts
- GitHub Pages

## Recursos implementados

- Layout responsivo para computadores, tablets e celulares.
- Navbar responsiva com menu dropdown.
- Cards de produtos.
- Formulário de pedidos com `input`, `select` e `textarea`.
- Tabela responsiva de prazos para encomendas.
- Validação básica dos campos obrigatórios.
- Botões e componentes estilizados com Bootstrap.

## Estrutura

- `index.html` — página inicial
- `salgados.html` — favoritos da casa
- `doces.html` — especialidades
- `bolos.html` — bolos personalizados
- `contato.html` — formulário e tabela de pedidos
- `css/styles.css` — estilos personalizados
- `imagem/` — imagens do projeto

## Como executar localmente

Abra o arquivo `index.html` em um navegador.
